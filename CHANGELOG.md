# Changelog

Every release of apogee-validation, newest first. Each is a `vX.Y.Z` tag with a GitHub
release carrying its section; the `grav` line in `grav.toml` says which
compiler versions it builds with.

## Unreleased

The first tagged release. Needs grav 1.7.0 or newer.

Validation for [Apogee](https://github.com/venomous-maker): a validator with Laravel's rules and messages (and a few more), wildcard fields, conditional rules, rule objects and closures, the database's `unique`/`exists`, files and image dimensions, errors that render themselves, `req.validate()`, and form requests that authorize and validate before a controller runs.
